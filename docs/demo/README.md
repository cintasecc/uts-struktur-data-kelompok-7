# Demo
1. Jalankan aplikasi.
2. Masuk dengan username `demo`, password apa pun, role Admin.
3. Buka Dashboard dan Data Putusan.
4. Coba pencarian `P001` atau nomor perkara.
5. Coba filter jenis narkotika.
6. Buka Import PDF dan pilih PDF yang memiliki text layer untuk preview.
7. Ekspor CSV/TXT melalui tab Ekspor.
